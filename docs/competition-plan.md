# Competition Plan

## Phase 0: Lab Control

- Establish reliable host control of the SIFT VM.
- Detect SIFT and Protocol SIFT readiness.
- Record a reproducible local setup path.

## Phase 1: Narrow Defensive Capability

- Pick one artifact lane first, likely Windows triage from mounted evidence or
  a small log bundle.
- Expose only the forensic functions needed for that lane.
- Emit structured findings and execution logs.

## Phase 2: Accuracy Story

- Add ground-truth fixtures.
- Score confirmed findings, misses, false positives, and unsupported claims.
- Verify evidence hashes before and after analysis.

## Phase 3: Standout Work

- Add self-correction when tools fail or evidence is incomplete.
- Correlate a second artifact source when it materially improves confidence.
- Produce a report that links every important claim to recorded tool output.
